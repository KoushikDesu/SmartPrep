# SmartPrep 🚀
> Next-Gen Placement Preparation & Interactive Practice Platform with AI Assistant

SmartPrep is an all-in-one placement preparation web application inspired by IndiaBIX, featuring real-time practice tracking, role-based dashboards (Students, Teachers, Admin), and an integrated AI tutor powered by Google Gemini.

---

## 🌟 Key Features

* 📱 **Interactive Practice Mode**:
  * One-question-at-a-time focused interface.
  * Real-time answer validation (Green for correct, Red for incorrect with correct option highlighted).
  * Comprehensive step-by-step mathematical explanations.
* 🤖 **AI Assistant (Gemini Flash)**:
  * Floating AI assistant with context-aware question resolution.
  * Step-by-step doubt clearing on Aptitude, Reasoning, Verbal, Engineering, and Coding.
* 📊 **Comprehensive Question Categories**:
  * **General Aptitude** (Arithmetic Aptitude — 35 Topics, Data Interpretation)
  * **Verbal & Reasoning** (Verbal Ability, Logical, Verbal & Nonverbal Reasoning)
  * **Engineering & Programming** (C, C++, Java, C#, Mechanical, Civil, ECE, EEE, CSE)
  * **Technical MCQs** (Networking, Database, Electronics)
  * **Interview Prep & Online Tests** (Placement Papers, HR, GD)
* 👨‍💼 **Admin & Teacher Portals**:
  * Admin: User management, reset passwords, create teacher accounts.
  * Teacher: Add/edit/delete questions by category and topic, track student performance, broadcast notifications.
* 💾 **Supabase Database & Authentication**:
  * PostgreSQL backend with Row-Level Security (RLS).
  * User profile management, password updates, and progress tracking.
* 🎨 **Modern & Fluid Design**:
  * Responsive layout with dark/light mode toggle.
  * Optimized typography, smooth micro-interactions, and accessible controls.

---

## 🛠️ Tech Stack

* **Frontend**: Vanilla JS, Vite, HTML5, Modern CSS (Design System Tokens)
* **Backend**: Supabase (PostgreSQL, Auth, Row-Level Security)
* **AI Model**: Google Gemini Flash
* **Icons & Fonts**: Material Design Icons, Inter, Space Grotesk

## 🚀 Getting Started

### 1. Clone & Install
```bash
git clone https://github.com/KoushikDesu/SmartPrep.git
cd SmartPrep
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
