# SmartPrep 🎓
> Intelligent Campus Placement Preparation & Aptitude Practice Platform

SmartPrep is a placement training platform built for students preparing for campus recruitment drives (TCS, Infosys, Wipro, Accenture, Cognizant, and core engineering companies).

---

## 🌟 Highlights
* 📚 **10+ Subject Categories & 54+ Topics**: Arithmetic Aptitude, Logical Reasoning, Verbal Ability, C Programming, Data Structures, and Database & SQL.
* 📝 **Interactive Practice Engine**: One-at-a-time practice with instant validation, formula references, and step-by-step mathematical explanations.
* 🤖 **AI Placement Assistant**: Powered by Google Gemini with placement doubt resolution and platform guidance.
* 👨‍🏫 **Faculty & Admin Studio**: Secure portals for authoring question banks, reviewing student accuracy rosters, and broadcasting campus notices.
* ☁️ **Cloud Database & Persistent Auth**: PostgreSQL backend powered by Supabase with live progress synchronization.
